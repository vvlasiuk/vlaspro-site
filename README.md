# VLASPRO — статичний сайт

Сайт із Google Sites (`sites.google.com/view/vlaspro`) переписаний у звичайні HTML-файли.
Жодного рушія, бази даних, збірки чи зовнішніх запитів — просто файли, які можна покласти
на будь-який хостинг.

## Структура

```
vlaspro_html/
├── index.html            головна
├── cases.html            кейси (5 кейсів + презентація у слайдері)
├── contacts.html         контакти
├── 404.html              сторінка помилки (підхоплюють майже всі статичні хостинги)
├── favicon.svg / .png    іконки сайту
├── apple-touch-icon.png  іконка для iOS
├── robots.txt
└── assets/
    ├── css/style.css     усе оформлення
    ├── css/fonts.css     локальні шрифти (@font-face)
    ├── js/main.js        єдиний скрипт — слайдер презентації
    ├── fonts/*.woff2     Inter, Roboto Slab, Lato (локально, 10 файлів)
    └── img/
        ├── banner.jpg/.webp        фон шапки
        ├── case-1..4.jpg/.webp     картинки кейсів
        └── slides/slide-01..19     19 слайдів презентації
```

Кожна картинка є у двох форматах: `.webp` (сучасні браузери, легша) і `.jpg` (запас).
Браузер сам вибирає потрібний — через `<picture>`.

## Як опублікувати

Достатньо завантажити **вміст цієї папки** в корінь хостингу. Варіанти:

- **Звичайний хостинг / cPanel / FTP** — скопіювати файли в `public_html`.
- **GitHub Pages** — залити папку в репозиторій, у налаштуваннях увімкнути Pages.
- **Netlify / Cloudflare Pages / Vercel** — перетягнути папку у вікно деплою, збірка не потрібна.

Головна сторінка — `index.html`, тож сайт відкриється сам за адресою домену.

### Локальний перегляд

Просто відкрити `index.html` подвійним кліком. Або підняти локальний сервер:

```bash
python -m http.server 8123
```

Далі відкрити http://localhost:8123

## Як редагувати

- **Текст** — прямо в `.html` файлах, звичайним редактором (Notepad++, VS Code).
  Тексти лежать у зрозумілих блоках з коментарями `<!-- КЕЙС 1 -->` тощо.
- **Кольори, розміри, відступи** — у `assets/css/style.css`, зверху в блоці `:root`
  (`--ink`, `--accent`, `--bg` і т.д.). Змінили одну змінну — змінився весь сайт.
- **Картинки** — покласти новий файл у `assets/img/` і замінити ім'я у `<picture>`.
- **Меню** — три однакові блоки `<nav class="nav">` у кожному html-файлі.

## Що варто зробити після підключення домену

1. У `robots.txt` розкомментувати рядок `Sitemap:` і вписати свій домен.
2. Додати `sitemap.xml` (за бажанням) з переліком трьох сторінок.
3. У метатегах `og:image` замінити відносний шлях на повний
   (`https://ваш-домен/assets/img/banner.jpg`) — щоб коректно показувалось прев'ю
   у Telegram, Viber і соцмережах.

## Технічні деталі

- Верстка адаптивна, перевірена на 320 / 375 / 640 / 900 / 1280 px — без горизонтального
  скролу.
- Контрастність тексту відповідає WCAG AA.
- Сайт працює і з вимкненим JavaScript: слайдер презентації тоді просто гортається
  пальцем/скролом, а розділи «Детальніше» відкриваються нативним `<details>`.
- Шрифти локальні, тому сайт не звертається до Google Fonts і не потребує інтернету
  для оформлення.
- Папка `.claude/` потрібна лише для локального перегляду — на хостинг її завантажувати
  не обов'язково.
